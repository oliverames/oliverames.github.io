Apple Core 1.3.0

Apple Core 1.3.0 fills in the Filesystem surface, which goes from 10 tools to 16. The theme is reaching things that were previously out of reach: what is inside a file rather than just its name, the part of a large file past the read cap, non-text files at all, and Finder tags.

Finding things

  • filesystem_search_content searches what is inside files, using Spotlight. It reaches into PDFs, Pages and Word documents and anything else Spotlight indexes, and answers immediately instead of walking the tree. Until now you could only search by file name.
  • filesystem_recent lists what changed most recently beneath a shared folder, for when someone refers to what they were just working on.

Both rely on Spotlight, so a volume with indexing switched off will come back empty. Searching by file name still works there.

Reading

  • filesystem_read accepts an offset and reports nextOffset, so a file larger than the 512KB cap can be read the rest of the way. Previously anything past the first page was simply unreachable.
  • filesystem_read_binary returns a non-text file as base64, up to 256KB. Larger files stay on disk, where they belong.
  • filesystem_hash gives a file's SHA-256, for checking that two files match or that a copy came through intact. It hashes in chunks, so it works on files far too large to hold in memory.

Writing and organising

  • filesystem_append adds text to the end of a file, creating it if it is not there. Adding a line no longer means reading a file back and rewriting it whole.
  • filesystem_tags reads and replaces Finder tags. Setting replaces the whole list, so read first if you are adding one to what is already there.

Upgrading

1.0.3 and later update automatically. Installs on 1.0.0 through 1.0.2 still need the one-time manual reinstall described in the 1.0.3 notes, because their update signing key does not match the feed.

Nothing here needs a new permission. The Filesystem surface still exposes nothing at all until you share a folder with it in Settings, and shared folders may overlap, so you can share a folder inside one you already share and give just that one write access.
