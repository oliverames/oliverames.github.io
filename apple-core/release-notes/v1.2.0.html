Apple Core 1.2.0

Apple Core 1.2.0 expands the two surfaces that were furthest from behaving like the cloud connectors they stand in for. Notes goes from 21 tools to 32, Filesystem from 5 to 10, and a listing bug that made several Notes tools look like a dead server is fixed.

Notes

  • Listing notes is fast again. notes_list resolved each note's folder with a separate request to Notes, so a default page of 50 outlived the client's patience and reported the server as unresponsive. It now fetches folders in bulk, and the cost no longer grows with the page size. The same call also returned every note twice; it does not any more.
  • New tools: notes_list_shared for notes shared with other people, notes_fetch_attachment for small attachments inline, and notes_show_folder, notes_show_account and notes_show_attachment alongside the existing notes_show.
  • notes_health_check answers quickly whether the surface is usable. notes_doctor reports Apple Events reachability, automation permission, account state and database access, each with what to do about it.
  • Four new tools read the local Notes database, because Notes offers no other route to them: notes_get_link for a note's notes:// deep link, notes_get_metadata for pinned and trashed state and the password hint, notes_get_checklist_state for which checklist items are ticked, and notes_get_sync_status. They need Full Disk Access and say so plainly when they do not have it. Every other Notes tool works without it, and notes_doctor tells you which case you are in.
  • Checklist state was previously invisible. Notes strips it out of the HTML body, so notes_get and notes_get_markdown show checklist items as ordinary list items and cannot tell you what is done.

Filesystem

  • Shared folders may now overlap. Sharing your home folder no longer silently blocks you from adding anything inside it, which is what made every folder after the first appear to do nothing. A narrower folder can be writable while the one containing it stays read-only, so you can grant writes to one place without opening up everything above it.
  • New tools: filesystem_stat, filesystem_create_folder, filesystem_move, filesystem_copy and filesystem_trash.
  • Deleting moves an item to the Trash. Nothing in this surface removes a file outright, so anything a client deletes can still be recovered.
  • Moving and copying refuse to overwrite. An overwritten file is the only thing here with no way back, because the replaced copy never reaches the Trash.
  • filesystem_list and filesystem_search accept limit and offset and report nextOffset. Search previously stopped at 200 matches without saying so, so there was no way to tell a complete result from a truncated one.

Headless Macs

Apple Core is often reached on a Mac nobody is sitting at. The five tools that open a window, the notes_show_* family and notes_selected, now refuse on a machine with no active desktop session instead of reporting success for a window that nobody can see. notes_selected was the worst of these, answering that no notes were selected, which looks exactly like a real answer.

Upgrading

1.0.3 and later update automatically. Installs on 1.0.0 through 1.0.2 still need the one-time manual reinstall described in the 1.0.3 notes, because their update signing key does not match the feed.

To use the four database-backed Notes tools, grant Apple Core Full Disk Access in System Settings under Privacy & Security, then quit and reopen it. Nothing else in Apple Core needs it.
