Apple Core 1.0.8

Fixed

  • Calendar and Reminders tools now return the item's identifier. Previously events_fetch, events_create, reminders_fetch, and the other read/create tools returned objects with no id, so events_update, events_delete, reminders_update, reminders_delete, and reminders_complete — which all require an identifier — could not be used through the API. Events expose their eventIdentifier and reminders their calendarItemIdentifier (as the JSON-LD @id), matching how each tool resolves the item.
  • calendars_list and the reminder-list tool now include each calendar's identifier.
