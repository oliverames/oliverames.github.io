Apple Core 1.1.0

Apple Core 1.1.0 grows the standard build from 77 tools to 106, adds a Filesystem surface bounded by the folders you share with it, and replaces the six-pane settings window with guided onboarding and three panes. It also carries an audit and adversarial review pass that repaired the server lifecycle, the connection approval flow, and several security edges.

New surfaces and tools

  • Filesystem (5 tools): filesystem_roots, filesystem_list, filesystem_read, filesystem_write, and filesystem_search, restricted to an explicit allowlist of folders you share in Settings. The surface reports itself inactive and exposes nothing until you share a folder, so a fresh install has no filesystem access at all.
  • Messages (5 tools): a direct chat.db reader replaces the blocked AppleScript path and unblocks attachment listing and per-chat filtering.
  • Contacts (12 tools): contact groups are readable and writable, and contact writes now cover the fields earlier builds could only read.
  • Reminders (7 tools): list sections are readable through a read-only store reader.
  • Calendar (6 tools): events carry attendees, and every tool sits under a single calendar_ prefix.
  • Utilities (6 tools): promoted from one placeholder tool to beep, notify, clipboard read, clipboard write, open URL, and system info.
  • Shortcuts (4 tools): folders, shortcut identifiers, file input, output paths, and output types are all reachable. File arguments resolve through the same shared-folder allowlist the Filesystem surface uses, so a shortcut cannot reach outside it.
  • Capture (4 tools): capture_list_windows makes displays and windows discoverable. Window and display capture accepted identifiers before this release but offered no way to learn one, so only whole-screen capture was reachable in practice. Capture also now says when the screen is locked instead of reporting no displays.
  • Maps: maps_directions reports distance and travel time, requests alternate routes, and respects departure and arrival times rather than always calculating against now. Its response shape changed, because the schema.org Trip type had nowhere to put those values.
  • Mail (28 tools) and Notes (21 tools) round out the standard build.

Surfaces start off except Maps and Utilities, so a fresh install advertises 11 tools until you enable more during onboarding or in Settings.

Setup and settings

  • Guided onboarding: a first-run sheet walks through macOS permissions, the surfaces you want, and connecting your first client.
  • Three panes instead of six: Services, Access, and Clients. Server internals and repair actions moved into a Diagnostics sheet.
  • One switch per surface: the separate per-service Remote toggle is gone. A surface you enable is reachable wherever Apple Core is currently served, and remote requests always authenticate. Access is never anonymous.
  • cloudflared installs from inside the app, and Cloudflare account setup is guided instead of assumed.

Security

  • Sparkle updated to 2.9.6, which hardens delta patching against a symbolic link at the destination path, hardens how the installer moves the download archive, and rejects package installs whose signature fails validation.
  • Query-string token authentication is removed. Simplifying the settings window took away the switch that controlled it while the server kept honoring the setting, leaving an active downgrade that nothing in the app could turn off. A bearer token in a URL leaks into server logs, proxy logs, browser history, and Referer headers, so it is gone rather than restored. Send the token in the Authorization header.
  • The filesystem gate refuses dangling symlinks at the final path component. Such a link previously read as a not-yet-created file, and the out-of-process writer downstream followed it wherever it pointed.
  • OAuth access tokens validate against the canonical <issuer>/mcp resource on every MCP route, so the legacy /sse and /message transports can authorize correctly.
  • Request bodies drain through a bounded reader, so an unauthenticated chunked request can no longer be buffered without limit.
  • Native clients may register reverse-domain private-use redirect URIs. Web redirects stay HTTPS-only and loopback callbacks stay local.
  • Reflected CORS responses carry Vary: Origin, so a shared cache cannot answer one origin with another origin's Access-Control-Allow-Origin.

Fixes

  • Integer arguments are accepted. JSON numbers without a decimal point decode as integers, while these tools declare a plain number, so integer coordinates were valid input that Weather rejected outright, Maps dropped region bias on, Calendar discarded proximity alarms for, and Capture replaced with defaults.
  • Starting the server stops any previous listener first, detects a bind failure, and reports it. Earlier builds could strand an orphaned port holder and show a green Running badge over a dead socket.
  • Approval dialogs are queued and shown one at a time. Concurrent clients used to overwrite each other's callbacks, dismiss each other's windows, and strand a client that could then never reconnect.
  • An approval dialog whose client gives up now resolves itself, closes, and presents whatever is queued behind it, instead of staying on screen with no live connection behind it.
  • Claude Desktop setup refuses to clobber an unreadable config. A claude_desktop_config.json that does not parse used to be replaced with an empty server map while the app promised existing servers were safe. The same protection now covers a corrupt Apple Core config.
  • messages_fetch clamps its limit to a sane range, rejects a one-sided date pair instead of dropping it, and counts unread messages independently of the truncated page.
  • Calendar and Reminders creation fails loudly when the requested calendar or list does not exist or cannot be written, matching how the update paths already behaved.
  • Contact birthdays are validated when the argument arrives, rather than failing later with an opaque framework error.
  • The bundled CLI recovers a lost session by clearing the stored Mcp-Session-Id on a 404 and returning a JSON-RPC error, instead of replaying a dead session header forever.
  • shortcuts list can no longer deadlock a call. Output is drained while the process terminates, under a 60 second timeout.

Upgrading

1.0.3 and later update automatically. Installs on 1.0.0 through 1.0.2 still need the one-time manual reinstall described in the 1.0.3 notes, because their update signing key does not match the feed.
